# 中学専用地図・記述・別問題の復習

2026年10月4日の実装記録。ゲーム本体は静的HTML/CSS/Vanilla JSのままで、ビルド、外部CDN、画像、フォント、実行時APIを追加していません。理科版は変更していません。

## 今回の追加

| 機能 | 初版の範囲 |
| --- | --- |
| 中学専用地図 | 地理・歴史・公民の3分野、12コース、各標準15・応用6・難問6 |
| 世界の諸地域 | 地域内の多様性、気候と農業、資源依存、都市化、地域比較 |
| 世界史との接続 | 交易・仏教の伝播、革命の年表、産業革命、日本の工業化との比較 |
| 金融・家計・消費生活 | 銀行、利息、支払総額、購買力、分散の限界、契約と相談 |
| 社会保障・公共の選択 | 制度の目的、財源、効率と公正、年齢構成、アクセス、成果の点検 |
| 記述・資料探究 | 32題。複数資料、模範解答例、3観点の自己評価、下書き保存 |
| 別問題の復習 | 7種類の誤答理由ごとに2問、計14問。別の数値・題材で同じ誤解を点検 |

今回の新作4択は108問です。既存216問は書き換えず、合計324問になりました。324問とは別に記述32題と復習専用14問があります。共有している資料や小学校の駅数を乗じた数は新作問題数に計上しません。

## 画面と進行

「中学」タブから全コースに入れます。小学校のクリアを前提にしない独立した導線です。既存の駅内の中学発展ボタンは従来通り基本クリア後に利用でき、同じコースの記録を共有します。戦争単元 `s6_rek11` の画面にはこの導線を追加していません。

専用地図では標準・応用・難問の習得と完了を表示します。記述回答は小学校の駅解放、中学4択の完了・全問正解、経験値、かけらの条件に含めません。別問題の復習も報酬・本コースの統計・完了記録に加算しません。

学習ノートの誤答理由と専用地図の復習提案から、別問題を開始できます。未習得の誤答理由を優先して提案し、手動で7種類から選ぶこともできます。元問題の誤答を同じ問題でやり直す従来の機能も残しています。初版の転移教材は各理由2問で、無限生成や個人向けAI生成ではありません。

## 記述の評価

自分の回答を記入した後、模範解答例と採点観点を表示します。各観点を「まだ書けていない」「一部書けた」「根拠とともに書けた」の0〜2で自己評価します。3観点すべてを選ぶまで記録できません。合計0〜6は自己評価であり、客観的な正答率ではありません。キーワード一致による自動採点は行いません。

下書き、模範解答表示中の状態、一部の評価を保存します。回答は最大2,000文字。保存前に書き直すことができ、保存済みの課題への再挑戦は最新回答と回数を記録します。学習ノートには回答・模範解答・観点を表示し、保護者レポートにはコース別の回答数と自己評価を4択の成績とは別に集計します。

## データと保存

- `data/middle-expansion.js`: 追加4コース・108問と専用地図の入口定義。
- `data/middle-written.js`: 記述32題。共有資料をコピーし、独自の設問・観点・模範解答を保持。
- `data/middle-review.js`: 誤答理由別の新作14問。
- `js/middle-renderer.js`: 地図、コース詳細、復習提案、記述一覧。
- `js/written-engine.js`: 記述の入力・評価・保存・再開。
- `middleProgress`: 既存と共通のコース・難度別の進捗。
- `practiceProgress`: 7理由ごとの初回回答統計と習得した問題ID。
- `writtenRecords`: 課題IDごとの回答・自己評価・回数・記録日時・教材版。
- `activeSession.kind: "written"`: 記述の下書きと評価段階を含む途中状態。

セーブキー `shakai_quest_save_v1` と内部スキーマ2は維持します。過去の中学記録を消さず、追加コースの未学習記録を補完します。記述課題の内容変更で途中状態が復元できない場合は `meta.archivedSession` に退避し、保存済み回答を保持します。破損・未知スキーマの保護も従来通りです。

## 教材の出典と表現

出題範囲は [文部科学省・中学校学習指導要領解説 社会編](https://www.mext.go.jp/content/20240919-mxt_kyoiku01-100002608.pdf) を基準にしています。教科書本文・実在史料の文章の転載はしていません。

銀行・金融の働きは [日本銀行の学習資料](https://www.boj.or.jp/about/education/oshiete.pdf)、通常の通信販売のクーリング・オフの扱いは [消費者庁・特定商取引法ガイド](https://www.no-trouble.caa.go.jp/qa/advertising.html-8) を確認しました。金融の計算条件は架空モデルで、実際の商品・投資・借入を推奨しません。契約上の救済は取引の状況により異なり、教材でも一律に否定せず相談先の確認を扱います。

社会保障の主要区分と目的は [厚生労働省・社会保障とは](https://www.mhlw.go.jp/stf/newpage_21479.html)、公的扶助の目的は [厚生労働省・生活保護制度](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/hukushi_kaigo/seikatsuhogo/seikatuhogo/index.html) を確認しました。医療費の負担割合・税・支援額の計算モデルは架空であり、現在の制度の一覧ではありません。

1776年の独立宣言は [米国国立公文書館](https://www.archives.gov/milestone-documents/declaration-of-independence)、1789年のフランス革命は [国立国会図書館の典拠](https://id.ndl.go.jp/auth/ndlsh/00563737)、イギリスの産業革命の時期は [Science Museumの資料](https://blog.sciencemuseum.org.uk/steaming-through-the-centuries/) を照合しました。史実の年表・説明は「学習用の要約」として、架空の数値表とは区別します。追加4コースの4択データは出典・確認年2026・確認日2026-10-04を持ちます。

## 検証

以下は今回の検証で、教材の専門的査読とは区別します。

- 全JS/MJS/CJS73ファイルの `node --check` と `check-data-integrity.mjs` が通過。
- `tests/regression.cjs`: 既存の回帰27項目。
- `tests/middle-extension.cjs`: 拡張の回帰13項目。全12コース・3難度の独立解放、108問のシャッフル・途中再開、記述32題、復習14問、保存移行、二重記録防止、正答・数値の独立確認、旧216問のファイル内容維持を検証。
- `tests/browser.cjs`: 旧中学216問の操作、既存の報酬・RPG・戦争単元、394点のSVGの非空ピクセルなど。
- `tests/middle-browser.cjs`: 追加108問・記述32題・復習14問を実際のChromeのボタン・入力・評価操作で実施。記述の下書きと途中評価を再読み込みして確認。
- PC1280・タブレット768・スマホ390幅で専用地図・コース・記述・レポートを確認。横あふれなし、操作領域44px以上、クイズ中の光演出なし。
- 印刷時はレポートだけを表示。`file://` 起動、コンソールエラー0、外部通信0を確認。

スクリーンショット・印刷PDFはOSの一時ディレクトリ `social-quest-qa` に出力します。テスト実行には既存のPlaywrightとChrome/Chromiumを用いますが、ゲーム本体への依存ではありません。
