## 増補前の実態

5・6年のextraには中学用語がすでに含まれていました。例は、s5_koku02の「複数のプレートが関係する位置」、s6_rek10の「領事裁判権」「関税自主権」、s6_kok02の「国連安全保障理事会」です。一方、`targetStage: middle_or_trivia` に小学校内容の復習と社会トリビアも混在していました。3・4年のextraは主に5・6年の基本問題の先取りであり、中学専用教材ではありませんでした。

従来の問題は変更せず、小学校の上位層が次の段階へ進むための専用コースを追加しました。

120問は新規・固有IDのオリジナル問題です。各ラインの駅はコースを共有します。通常バンク2017レコードとは別の120問で、共有コースを駅数倍した数は教材量に計上しません。

計算・資料読み取り、比較、因果関係、調べ方、条件を踏まえた判断を中心に構成しました。難しい用語を増やすだけではなく、分母・単位・割合と絶対量・相関と因果・支援の投入量と成果・史料の立場などを区別します。

具体例:

- 人口と面積から密度を算出し、総人口が多い地域と密度が高い地域を区別する。
- 1ドル100円から125円への変化で、100ドルの輸入原料に必要な円と、1万円の輸出品のドル価格をそれぞれ計算する。
- 100人の群と300人の群の賛成率から全体の賛成率を算出し、単純平均との差を説明する。
- 1894年の条約調印と1899年の実施、1951年の平和条約調印と1952年の発効を区別する。
- 架空の役所の記録と町人の日記を読み、書き手の立場や物価、ほかの史料との照合が必要な理由を考える。

誤答は計算の分母・単位や因果の逆転などを中心に、同じ問いの範囲で文型をそろえています。正答位置はデータ内でも0〜3に分散し、出題時には問題順・選択肢・正解インデックスをコピー上でシャッフルします。

## 進行と保存

5・6年の該当駅の基本クリア後に「中学発展」が利用できます。小学校の認定は同学年範囲のままです。中学発展はextraセッションですが、通常のおまけとは別バンク・別進捗です。

- 同一ラインで同じコース記録を共有し、分岐からも開始・再開できる。
- `middleProgress` に経験・習得・初回回答の集計・最高正解・完了・初回全問正解を保存する。
- 学び直しは誤答を再出題し、再出題の正解や復習で初回集計・EXP・かけらを増やさない。
- RPG挑戦はライフと初回正答率80%以上を判定し、会心・盾・ヒントで正解数を増やさない。
- 通常回答に報酬、初回コース完了に80EXP、再完了に20EXP。専用レアや小学校のextra実績は付与しない。
- 同じセッションの報酬は重複付与しない。小学校の解放・tierフラグ・tier統計を変更しない。
- 学習ノートと保護者レポートで記録を確認でき、レポートだけを印刷できる。
- `s6_rek11` からは中学コースを開始できない。既存の抑えた資料学習の演出を維持する。
- セーブキーとスキーマ2を維持。従来セーブは新しい記録だけを補完し、破損データは保護する。

## 応用・難問の追加（96問）

標準15問は問題文・選択肢・IDを変えず保持し、8コースそれぞれに応用6問・難問6問を追加しました。中学発展は各27問、合計216問です。単なる数合わせを避け、各難度を3つの資料セットと、各セットで異なる視点を問う2問で構成しています。

各問で2〜3資料を表示します。数量の表と条件文、二つの記録、費用表と利用者の条件などを照合します。解説に資料A・B・Cの根拠を分けて表示し、回答後も参照できます。原文や教科書図版の転載はありません。

| 分野 | 応用6問の焦点 | 難問6問の焦点 |
| --- | --- | --- |
| 国土 | 密度と年齢構成、冬の気候と栽培条件、縮尺と避難経路 | 自然・社会増減、分母変更と推論限界、避難の複数条件 |
| 食料 | 面積当たり収穫、需要供給、熱量の加重平均 | 供給先の共通リスク、水と予算の制約、増収の原因の検証 |
| 工業 | 立地の総費用、為替と輸入費、不良の割合 | 円安と部品値上がり、発電の複数制約、付加価値の配分 |
| 情報 | 分母の違い、配送の前後比較、割合の集計対象 | 標本と母集団、比較群と値上げ、転載と独立した根拠 |
| 環境 | 節水量と世帯数、観測条件、ごみの削減 | 合意された制約、一人当たりと合計、製造と使用の排出 |
| 政治 | 投票率と得票率、公共の利用条件、架空の支援規則 | 予算の優先順位、架空の段階的課税、福祉の効率と公平性 |
| 歴史 | 統治の違い、教育制度と実態、通貨と輸送 | 制度と普及の順序、現物と金額の負担、史料の範囲と因果 |
| 国際 | 給水量と不足、現地で続ける協力、貿易収支 | 教育の利用機会、航路の共通リスク、維持費を含む協力 |

3難度は基本クリア後に自由に選択できます。標準全問のクリアを応用の前提にはしていません。上位層が必要な難度へ直接進める一方、記録は難度別です。小学校の基本・認定の範囲は拡張しません。

誤答には「割合の分母」「条件の照合」「原因と結果」「年代・前後関係」「資料が示す範囲」「両立と優先順位」「単位・縮尺」のラベルを設定しました。学習ノートで着目点を絞り、そのコース・難度の未解決の誤答だけを復習できます。正解後は未解決候補から除きます。これは選んだ選択肢に基づく分類で、学習者の思考そのものを診断するものではありません。

旧 `middleProgress[courseId]` は標準の記録のまま維持し、`levels.applied` と `levels.hard` を追加しました。`questionStats.lastMistake` に最後の誤答の着目点を保存します。旧セーブでは追加領域だけを初期化し、標準の途中セッションもそのまま再開できます。資料・根拠・選択肢と誤答理由の対応は再開時に検証します。

応用・難問も全件コースです。再出題・復習・ヒントの扱いは標準と同じで、初回正答数やノーミスを水増ししません。初回完了80EXP、再完了20EXPは難度ごとで、小学校のレア報酬は付けません。保護者レポートは8分野×3難度の24行に拡張しました。

追加96問は全問の選択肢、正答、資料の条件、説明を作成時に照合し、数値問題の33か所は独立した計算式との一致も自動検証しています。対策の効果は架空モデル内の結果であり、実際の政策・価格・排出量の予測ではありません。歴史の模擬記録は当時の原文でも偉人の発言でもありません。金融・社会保障を含む公民の全領域をこれで網羅したとはしていません。

## 未完了・次の増補
