# 時空社会御朱印帳

小学3〜6年の社会を学ぶ、ビルド不要の静的な学習RPGです。理科版の進行・保存・装備の考え方を参考に、社会の資料読み取りや地域を調べる活動へ組み直しています。

## 起動

`shakai-quest/index.html` をブラウザで開きます。サーバー、npm、外部CDNは不要です。配信する場合も `shakai-quest/` をそのまま配置できます。

## 現在の教材

| 学年 | 駅 | 内容 |
| --- | ---: | --- |
| 3年 | 7 | まち・仕事・安全・移り変わりの全国共通編 |
| 4年 | 9 | 県・水とごみ・防災・文化・地域の全国共通編 |
| 5年 | 19 | 国土・食料生産・工業・情報・環境（既存教材） |
| 6年 | 17 | 政治・歴史・国際（既存教材） |

合計52駅、分岐を含め57経路です。東京書籍「新編 新しい社会」令和6年度版の単元一覧を基準にしています。3・4年の対象地域は未指定です。実在する市町村・施設・人物・統計を勝手に補わず、全国共通の学び方と一般事項を実装しています。

**教材の完成範囲:** 3・4年は各経路で基本10問・認定5問の初版です。目標20/10問への増補、地域教材、教科書原本との最終照合、教員による教材査読は未完了です。おまけ15問は既存の社会教材を先取りとして共有し、元問題IDと対象学年を記録しています。収蔵品の名称・説明、既存36駅の問題ファイルは保持しています。教材量2017件は共有・先取りを含むレコード数で、独立した新作問題数ではありません。

### 上位層向けの中学発展

従来の「おまけ・先取り」とは別に、**中学発展12コース・各27問、計324問の新作4択** を用意しています。各コースは標準15問・応用6問・難問6問です。「中学」タブの地理・歴史・公民の専用地図から、小学校のクリア状況に関係なく選べます。既存8コースに、世界の諸地域、世界史との接続、金融・家計・消費生活、社会保障の4コース108問を追加しました。

地理・歴史・公民の橋渡しとして、人口密度・年較差・工業立地・円高円安・統計の分母と標本・史料の立場・立憲主義・効率と公正・国際協力などを扱います。暗記だけでなく、計算、比較、理由、根拠の点検を中心に構成しています。架空の数値モデルにはその旨を表示し、実際の歴史の学習用要約とは区別しています。出題範囲・対象分野・参考資料を問題データに記録しています。

応用・難問の144問は、2〜3資料の照合、加重平均、条件付きの選択、因果の検討などを扱います。解説では資料ごとの根拠を示し、「割合の分母」「条件の照合」「原因と結果」など7種の着目点を記録します。学習ノートから元問題を復習するほか、同じ誤りを別の題材で確かめる専用14問を選べます。中学地図には未習得の誤答理由からの復習提案も表示します。復習の正答率・習得は本コースと分け、報酬や完了記録を水増ししません。

**記述・資料探究32題** では、回答の下書き、模範解答例、3つの採点観点、自己評価を保存できます。自動採点ではなく、4択の正答率・経験値とは別の記録です。下書きや一部の自己評価を含めて途中再開でき、学習ノートと保護者レポートにも表示します。

コースの進捗はコース・難度ごとに保存し、小学校の駅解放、既存のおまけ全問正解、単元専用レアの条件には混ぜません。既存216問の内容と学習履歴も維持します。従来の駅内導線は基本クリア後に利用でき、同じラインの駅は同じコースを共有します。戦争単元 `s6_rek11` にはこの導線を出しません。税率・支援額・金融商品の数値は明記された架空条件で、実際の制度や商品を推奨するものではありません。

中学全範囲・高校入試対策の完成版ではなく、科目専門家による査読も未完了です。最新の機能・出典・検証は [docs/middle-portal-2026-10-04.md](docs/middle-portal-2026-10-04.md)、先行増補の記録は [docs/middle-enrichment.md](docs/middle-enrichment.md) に記載しています。

## 遊び方と保存

- 学年ごとに地図を選択。各ラインの最初の駅は最初から開放し、5年を終えなくても6年の政治・歴史・世界に進めます。
- 基本は全問を標準にし、5問・10問の短いコースも選択できます。短いコースの抽選袋は保存され、袋を使い切るまで同じ問題を再抽選しません。
- 学び直しはライフを減らさず、誤答を最後に再出題します。RPG挑戦はライフ制で、初回正答率80%以上が成功条件です。ダメージや装備で正解数を増やしません。
- 次駅の開放には基本バンク全件の経験と習得が必要です。学び直しは全件習得、RPG挑戦は全件経験＋80%以上習得が条件です。短い5問だけで次へは進めません。
- 設問順・4択の選択肢・正解位置は毎回シャッフル。途中の順序・回答・解説・装備効果はセーブして再開できます。
- 通常の架空モチーフキャラ3体を各駅に配置し、5問ごとに交代。未遭遇を優先し、装備・仲間の図鑑から対象を指定できます。実在の人物や民族などは敵にしません。
- 4装備スロット、仲間2体、ヒントと回復。認定の初回成功で架空の精の仲間・カード・EXP、初回全問正解の再挑戦で未所持の通常装備、おまけ15問の初回全問正解・ヒント不使用で専用★レアを付与します。既存の実用アイテム4件も対応駅のおまけから入手できます。
- 基本再訪で同じ駅の未入手名産品を順に取得。分岐は両方に挑戦でき、経路ごとの記録を保持します。
- 戦争単元 `s6_rek11` は資料を読み解く学習のみ。敵・ライフ・戦闘音・祝祭的な完了演出を使いません。
- 学習ノート、18実績、技能別集計、保護者レポート、レポートのみの印刷に対応。

社会専用キー `shakai_quest_save_v1` の内部スキーマを2へ移行します。既存の収蔵品・進捗・経験値を維持し、理科のセーブは読み書きしません。破損や未知のスキーマは元データを保護し、設定からJSONを書き出せます。更新された途中セッションは `meta.archivedSession` に退避し、学習履歴は残します。保存容量不足なども通知します。読み込み前にJSONを書き出しておくことを推奨します。

## 構成と検証

設計・出典・未完了範囲は [docs/grades3-6-design.md](docs/grades3-6-design.md) を参照してください。通常のscriptタグでデータ、出題モデル、状態、RPG効果、報酬、描画、UIを分離しています。

```powershell
node shakai-quest/scripts/check-data-integrity.mjs
node shakai-quest/tests/regression.cjs
node shakai-quest/tests/middle-extension.cjs
node shakai-quest/tests/browser.cjs
node shakai-quest/tests/middle-browser.cjs
```

ブラウザテストだけはテスト環境にPlaywrightとChrome/Chromiumが必要です。ゲーム本体には依存しません。既存のPlaywrightの配置先を `NODE_PATH`、Chromiumの実行ファイルを `PLAYWRIGHT_CHROMIUM_EXECUTABLE` で指定できます。スクリーンショットと印刷PDFはOSの一時ディレクトリ `social-quest-qa` に出力します。

参照実装: [science-RPG / 67a59c0](https://github.com/Kou-no1/science-RPG/tree/67a59c03bc2da3d65a2fc6ce1f0ae568a54a8c03)。理科版は変更していません。社会版の保存先は [shakai-journey](https://github.com/Kou-no1/shakai-journey) です。
